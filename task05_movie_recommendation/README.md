# Task 5 — Movie Recommendation System (Level 2)

**Dataset :** MovieLens 100K (Kaggle)
**Objectif :** Recommander des films par similarité utilisateur.
**Topics :** Systèmes de recommandation | Similarité

2. Scores de similarité

4. Évaluation via precision@K
