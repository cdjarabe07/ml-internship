# Task 1 — Student Score Prediction (Level 1)

**Dataset :** Student Performance Factors (Kaggle)
**Objectif :** Prédire les scores dexamen à partir des heures détude.
**Topics :** Régression | Métriques d’évaluation

## Étapes
1. Nettoyage des données + visualisation exploratoire
2. Split train/test
3. Régression linéaire
4. Visualisation des prédictions + évaluation (MAE, RMSE, R²)

## Bonus
- Régression polynomiale (comparer les performances)
- Tester différentes combinaisons de features (sommeil, participation, etc.)
