# Task 6 — Music Genre Classification (Level 3)

**Dataset :** GTZAN (Kaggle)
**Objectif :** Classifier des morceaux par genre à partir de features audio.
**Topics :** Données audio / CNN | Classification multi-classe

2. Modèle multi-classe (tabulaire ou image)
3. Si image : CNN

## Bonus
