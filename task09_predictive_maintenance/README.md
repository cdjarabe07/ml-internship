# Task 9 — Industrial Predictive Maintenance (Industry Level)

**Dataset :** AI4I 2020 Predictive Maintenance (UCI/Kaggle)
**Contexte :** Minimiser les fausses alertes coûteuses, pas juste maximiser laccuracy.
**Topics :** Détection danomalies | Cost-sensitive learning | Feature engineering

## Étapes
1. Classifieur de type de panne (usure outil, surchauffe...) à partir des capteurs
2. Évaluation centrée sur le False Discovery Rate
3. Tuning pour minimiser les faux positifs

## Bonus
- Modèle de régression "Time-to-Failure" (durée de vie restante)
- Corrélation pour identifier lindicateur précoce de panne
