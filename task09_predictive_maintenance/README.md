## English

# Task 9 — Industrial Predictive Maintenance (Industry Level)

**Dataset:** AI4I 2020 Predictive Maintenance (UCI/Kaggle)
**Context:** Minimize costly false alerts, not just maximize accuracy.
**Topics:** Anomaly detection | Cost-sensitive learning | Feature engineering

## Steps
1. Classifier of fault type (tool wear, overheating, etc.) from sensors
2. Evaluation focused on the False Discovery Rate
3. Tuning to minimize false positives

## Bonuses
- Time-to-Failure regression model
- Correlation to identify early indicator of failure
