# Task 2 — Customer Segmentation (Level 1)

**Dataset :** Mall Customer (Kaggle)
**Objectif :** Segmenter les clients par revenu et score de dépense.
**Topics :** Clustering | Apprentissage non supervisé

## Étapes
1. Scaling des features
2. Exploration visuelle des groupes
3. K-Means + détermination du nombre optimal de clusters (elbow/silhouette)
4. Visualisation 2D des clusters

## Bonus
- Autres algos de clustering (DBSCAN)
- Analyser la dépense moyenne par cluster
